XiaoZheng Threads Radar

XiaoZheng Threads Radar is an internal social media management tool designed to help an authorized Threads user discover relevant public conversations on Threads.

The application uses the official Threads API to search public Threads posts based on user-defined keywords. Search results may include publicly available information such as post text, username, timestamp, and permalink.

The application does not sell personal information, infer sensitive personal attributes, or automatically contact Threads users.
