Privacy Policy

Last updated: August 13, 2026

XiaoZheng Threads Radar is an internal social media management tool that uses the official Threads API to help an authorized Threads user discover relevant public conversations.

Information We Access

When authorized through Threads, the application may access information permitted by the Threads API. Depending on the features used, this may include:

  • Threads user account information required for authentication
  • Public Threads post text
  • Public usernames
  • Post timestamps
  • Public Threads permalinks

How We Use Information

Information is used only to search, review, organize, and evaluate relevant public Threads conversations for manual social media engagement.

What We Do Not Do

  • We do not sell personal information.
  • We do not infer sensitive personal attributes.
  • We do not create sensitive user profiles.
  • We do not automatically contact Threads users.
  • We do not use Threads data for unlawful surveillance.

Data Retention

Data obtained through the Threads API is retained only as reasonably necessary for the application's stated functionality and is deleted when no longer required.

Data Deletion

Users may request deletion of application-related data by following the instructions on the User Data Deletion Instructions page.

Third-Party Services

XiaoZheng Threads Radar uses Meta's Threads API. Use of Threads and Meta services is also subject to Meta's applicable terms and privacy policies.

Contact

For privacy-related questions or data deletion requests, please contact the application owner using the contact information registered with the XiaoZheng Threads Radar application on Meta for Developers.
